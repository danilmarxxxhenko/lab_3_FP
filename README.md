# Лабораторна робота №3 з функціонального програмування

Варіант 11. Програма на Haskell читає текст підручника з програмування з файлу і в кожному реченні видаляє підрядок максимальної довжини, що починається і закінчується заданими символами. Табуляції та послідовності пробілів замінюються одним пробілом.

Текст подано власними типами: `Symbol`, `Word`, `Punctuation`, `Element`, `Sentence`, `Text`. Для перетворення назад у рядок описано клас `Render` з instance для кожного типу.

## Файли

- `Main.hs` – код програми
- `textbook.txt` – тестовий текст (з табуляціями і зайвими пробілами)
- `lab3.cabal` – опис проєкту
- `Лабораторна_3_Марченко.docx` – звіт

## Запуск

```
cabal build
cabal run lab3
```

Програма запитує файл (за замовчуванням `textbook.txt`), початковий і кінцевий символи. Для кожного речення вона виводить, що з нього видалено, а новий текст записує у `result.txt`.
